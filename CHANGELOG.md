## [0.4.0] - 2026-03-10

### Added
- Initial release of Free File.
- Core file management capabilities:
    - Navigation via Tree View and Address Bar.
    - Multiple view modes: List, Grid, and Details.
    - Tabbed browsing support.
- Native macOS integration:
    - Transparency and vibrancy support.
    - Native-style window controls and title bar.
- Keyboard shortcuts for common actions.
- Support for dragging and dropping files.
- Localization support (via `l10n` package).
- Dark and Light mode themes.
